# Sprints — Especificações

Esta pasta guarda a **especificação** de cada Sprint (o que deveria ser entregue, escopo,
critérios de aceite) — escrita **antes** da execução. O resultado real da execução (o que foi
entregue de fato, problemas encontrados, parecer do Reviewer) vive em `docs/reviews/`, com o
mesmo número de Sprint.

- `docs/sprints/SPRINT_00X.md` — o que foi pedido.
- `docs/reviews/SPRINT_00X.md` — o que foi entregue (relatório + parecer do Reviewer).

Sprint com sub-fase usa sufixo `_Y` (ex.: `SPRINT_003_1.md` para a Sprint 3.1).

## Histórico

As Sprints 1 a 3.1 não tiveram uma especificação guardada como arquivo próprio nesta pasta — o
escopo foi combinado diretamente na conversa com o usuário antes de cada uma. Os relatórios
correspondentes (`docs/reviews/SPRINT_001.md` a `SPRINT_003_1.md`) continuam sendo o registro
fiel do que foi entregue em cada uma. Esta pasta passa a existir a partir da Sprint 4, cuja
especificação é o primeiro `SPRINT_00X.md` real guardado aqui.
